## 1. What changed today (three waves)

### Wave 1 — Sunburst interactives readability
- `build_micro_sunburst.py` (Plotly) & `build_micro_sunburst2.py` (D3):
  bigger plates (760→920px / D3 cap 720→880px), larger nucleus and specimen
  slip typography, wedge labels 15px, and a new bilingual **quick-stats
  strip** (20,881 samples · 28.1% NC of known validity · 83 unknown · top NC
  category).

### Wave 2 — GSO panel-completeness fix
- 7 test-name spelling aliases in `enrich_gso.py` (`TEST_ALIAS_TO_CANONICAL`):
  Listeria ×2, yeasts, Campylobacter, B. cereus, Aeromonas,
  P. aeruginosa↔سيدومومناس (user-confirmed).
- Result: false "incomplete panel" flags cleared — **5,100 → 4,090**.
- Dashboard GSO-audit card now splits incomplete panels into **systematic**
  (lab skips the test for ≥90% of samples under the same code) vs **sporadic**
  via new payload column `panel_gap_kind` (index 25).

### Wave 3 — Data-quality flags cleanup
- ISO placeholder (1,328 swab samples) reclassified as informational
  `iso_method_outside_gso1016` — swabs are correctly outside GSO 1016.
- 'H'-code samples (36) mapped by product name: cheddar→A-13 (25),
  ketchup→G-2 (2), other sauces→G-3 (9); flag `gso_code_h_mapped_by_name`.
- `>10`/`<10` prefixed results: prefix-hinged lab-vs-GSO disagreements now
  `ambiguous_prefixed_result` (new column `gso_lab_vs_gso_ambiguous`,
  dashboard card "↳ ambiguous (>10 convention)"). Disagreements 80 → 51 true
  + 29 ambiguous.
- Schema aliases: C. botulinum typo (22 rows), Fecal→Faecal Coliforms (1);
  `test_value_unrecognised` = 0.
- Landing page: chemistry card now shows a **✕ cross** over a greyed plate
  with all three entries disabled (no links) — "under construction · قيد
  الإنشاء".

## 3. How to regenerate (from repo root, `python3`)
```bash
python3 microbiology/scripts/clean_2024.py --year 2024        # source → parquets
python3 microbiology/scripts/enrich_gso.py                    # GSO codes, limits, audit
python3 microbiology/scripts/build_dashboard_combined.py      # main dashboard
python3 microbiology/scripts/build_micro_sunburst.py          # Plotly plate
python3 microbiology/scripts/build_micro_sunburst2.py         # D3 plate
python3 build_landing.py                                      # index.html hub
```
Order matters: clean → enrich → dashboards. 2025 cleaning only needed if the
source changes: `python3 microbiology/scripts/clean_2025.py "microbiology/2025-original/Data 2025.xlsx" microbiology/cleaned/data2025.parquet microbiology/reports/data2025_diff.md`
