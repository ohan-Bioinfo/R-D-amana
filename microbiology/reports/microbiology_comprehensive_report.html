GSO Classification & Categorization Challenges

A. Precedence Rules & Contextual Ambiguity

Sauce vs. Main Dish: Distinguishing between صوص برجر (sauce is the product) vs برجر لحم بصوص (sauce is a condiment). The rule engine requires whole-token scanning with sauce-head precedence to avoid assigning cooked foods into sauce categories.
Substring False Positives: Arabic substring matching for رز (Rice) falsely matches inside كرز (Cherry) and سنيكرز (Snickers). Strict whole-token bounds prevent this.

B. Swab vs. Food Samples

Environmental swabs (مسحة طاولة) are entered in the same columns as food samples with placeholder GSO codes. A dedicated detection layer isolates the word مسحة into a swab bucket. Wash-water swabs (غسيل رز) are pushed to the N-3 water bucket instead.

C. Placeholder Codes & 2025 Extrapolation

Code "H": 36 samples used a placeholder letter — mapped by product name (e.g., Cheddar → A-13). 2025: No GSO column at all. Tier 1 exact-name matching against 2024 achieved ~37% initial coverage, with strict equality to prevent false friends (جبنة بيتزا ≠ لبنه بيتزا).

Data Quality & Statistical Challenges

A. Lab Validity Conflicts

Rows marked "Valid/Pass" despite having failed pathogen tests, and rows marked "Invalid/Fail" with no failures. Resolution: Objective test list (n_failed_tests > 0) overrides the subjective validity column. 9 conflicts resolved in 2025.

B. Denominator Honesty

Statistical threshold (min 20 samples) enforced before calculating percentages to prevent noise (e.g., 1/1 = "100% failure").

C. Date Parsing Anomalies

Raw sheets contained dates recorded as 2026, 2027, 2028 — coerced back to 2025 via date logic.

D. Test-Name Alias Normalization

لستيريا, L.monocytogenes, الليستيريا → single canonical form. CAMPYLOPACTER vs كامبيلوباكتر merged. 7 alias mappings applied.

E. RTL Numeric Flipping (>10 Convention)

14,120 rows in 2024 carried a >10 prefix — confirmed as an RTL data-entry flip for <10 (below reporting limit = pass). Without this fix, thousands of compliant samples would have been falsely flagged as failures.

Enhancement Opportunities

🔴 Priority 1 — Data Gaps That Block Features BLOCKING

P1.1 2025 Test-Level Data Missing

Panel completeness & GSO limit cross-checks are 2024-only. The GSO & Quality tab is half-empty for 2025. Requires the lab to provide a LIMS export (one row per test).

P1.2 2024 Official Numbers = null

Compliance card reads "pending reconciliation". Need official 2024 totals from the lab to populate OFFICIAL_COMPLIANCE[2024].

P1.3 2025 Annual Report +160 Discrepancy

Our 11,564 vs official 11,404. No single exclusion rule reproduces 11,404. Need the lab's exact inclusion criteria.

P1.4 2024 Has No Facility/Chain Data

5 charts are tagged data-needs-year="2025" and hidden when viewing 2024 alone. If facility data exists in the 2024 source, it should be extracted.

P1.5 3,751 Uncoded 2025 Samples (Group B)

32% of 2025 falls into "Miscellaneous Foods", inflating that bucket in every chart. Requires Group B disambiguation + Tier-1c heuristics.

🟡 Priority 2 — Missing Analytical Dimensions ANALYTICAL

P2.1 Quarter-over-Quarter Chart Low effort

The quarter column is already in the payload but no chart uses it. A QoQ stacked bar would show seasonal patterns more clearly than the monthly trend.

P2.2 Facility-Level Drilldown Table Medium effort

Lowest granularity today is "chain". A searchable table showing individual facility branches (name, sample count, NC rate) would be directly actionable by inspectors.

P2.3 Pathogen Co-Occurrence Matrix Medium effort

Which pathogens appear together? A symmetric heatmap of co-occurrence counts (e.g., Salmonella + E.coli O157 co-fail rate). Data exists in failed_tests arrays.

P2.4 Month-over-Month Delta KPIs Medium effort

Add ▲/▼ trend arrows to KPIs showing change vs. previous month. Currently they are static snapshots — deltas would make them tell a story.

P2.5 Compliance Trajectory Sparkline Low effort

A 12-month inline SVG sparkline inside the "Compliance rate" KPI card showing the trend direction at a glance.

P2.6 "Organisms & Tests" Tab Is Thin Medium-high

Only 2 charts. Add: organism prevalence radar chart, pathogen seasonality small multiples, "zero-detection streak" tracker per pathogen.

🟢 Priority 3 — UX/UI Polish UX/UI

P3.1 Export to PDF / Excel

📥 "Download Report" button capturing filtered view as PDF or Excel. Critical for field inspectors who need offline printouts.

P3.2 Dark Mode Toggle

CSS already uses --var design system. A dark mode toggle is straightforward — appreciated by night-shift analysts.

P3.3 Print Stylesheet

@media print rules so the dashboard prints cleanly on A4 — hide filters, one chart per page, KPIs as header.

P3.5 Cross-Linking Standalone Interactives

Clicking a node in the Sankey/Treemap/Network should deep-link to the main dashboard with pre-applied filters. Currently isolated.

P3.6 Responsive Mobile Layout

Dashboard is desktop-first (1600px max). Add responsive breakpoints for tablet use during field inspections.

P3.7 Loading Skeleton

The 7.2 MB HTML takes time to parse. A CSS skeleton screen would show immediately while JS initializes.

🔵 Priority 4 — Advanced / Future STRATEGIC

P4.1 Predictive Time-Series Forecasting

Seasonal decomposition (STL) on the 24-month baseline to forecast next-quarter NC rates. Surface as "Projected NC %" with confidence bands.

P4.2 DuckDB-WASM Backend

Replace 7.2 MB inline JSON with .parquet loaded via DuckDB-WASM. ~80% load-time reduction. Future-proofs for 100K+ rows.

P4.3 Geocoded Facility Map

Replace sector-centroid bubbles with actual lat/lon per facility. Individual restaurant pins clustered by neighborhood.

P4.4 Automated Inspection Target List

"Generate Top 50 Risk Facilities" button exporting a prioritized inspection schedule based on repeat offenders + pathogen severity + recency.

P4.5 Chemistry × Microbiology Cross-Correlation

Unified view correlating chemical hazards with microbiology failures at the same facility.

P4.6 "What-If" Threshold Slider

Model stricter-than-GSO limits dynamically (e.g., "what if Listeria zero-tolerance applied to cakes?").
