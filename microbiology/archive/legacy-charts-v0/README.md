## طريقة الاستخدام

### 0. الفحص التشخيصي (اختياري - يُنصح بتشغيله أولاً)
```bash
cd food_analysis
python 00_date_diagnostic.py
```
**الوظيفة:** فحص التواريخ في ملف البيانات والتأكد من صحة التحويل وعرض أي تواريخ خاطئة

### 1. التحليل الإحصائي
```bash
python 01_statistics.py
```
**المخرجات:**
- طباعة إحصائيات شاملة في الشاشة
- ملف إكسل: `نتائج_التحليل_الإحصائي.xlsx` (6 أوراق)

**التحليلات:**
- الملخص الإحصائي العام
- أكثر 20 منشأة تلوثاً (مع درجة الخطورة - معادلة WHO المحسنة)
- أكثر 20 عينة تلوثاً (بالنسبة وخطورة الميكروبات)
- أكثر الاختبارات/الميكروبات غير مطابقة
- التحليل الموسمي والشهري
- تحليل البلديات

### 2. الرسوم البيانية

python 02_charts.py

## معادلة تقييم المخاطر (WHO/Codex Alimentarius المحسنة)

```
درجة المخاطر الكلية = 
    (نسبة عدم المطابقة / الحد الأقصى × 35%) +
    (شدة الميكروبات المرضية المرجحة / الحد الأقصى × 30%) +
    (تنوع الميكروبات / الحد الأقصى × 20%) +
    (log(إجمالي العينات) / الحد الأقصى × 15%)

مع معامل تعديل:
    × 0.50 للمنشآت بعينة واحدة
    × 0.75 للمنشآت بعينتين
    × 1.00 للمنشآت بـ 3 عينات فأكثر
```

**تصنيف المخاطر:**

| الدرجة | التصنيف | اللون |
|---|---|---|
| 70+ | حرجة | أحمر غامق |
| 50-69 | عالية | برتقالي |
| 30-49 | متوسطة | أصفر |
| 1-29 | منخفضة | أخضر |
| 0 | آمنة | رمادي |

يتم استثناء الاختبارات التالية من جميع التحليلات (مؤشرات عامة غير مرضية):

## معالجة التواريخ

جميع السكربتات تتضمن:
1. تحويل التواريخ بصيغة DD/MM/YYYY (dayfirst=True)
2. فلتر تلقائي يستبعد أي تواريخ خارج سنة 2025
3. رسالة تشخيصية تُطبع عند استبعاد صفوف

يُنصح بتشغيل `00_date_diagnostic.py` أولاً للتحقق من سلامة التواريخ.
