# Microbiology Dashboard — Tabbed, Touch-First Redesign — Design

**Date:** 2026-08-10
**Status:** Approved for spec review (Muhannad)
**Scope:** microbiology only — `microbiology/reports/microbiology_dashboard.html`
(generated by `scripts/build_dashboard_combined.py`)

## Goal

Reorganize the core microbiology dashboard from one long scroll of ~13 dense
panels into a **5-tab, touch-first instrument**: every chart is zoom/pinch/pan
and click-to-drill, the busy dual-axis/scatter charts are cleaned up, redundant
charts are cut or tucked, and GSO information gets its own **sortable** tab.
Represent the numbers, categories, and GSO info clearly — no new data judgments.

## Current state (what exists)

- One-page scroll: KPIs → filter bar (year/time/location/product/microbe/excludes,
  Views/bookmarks) → ~13 chart panels → tables.
- Chart mix: **18 bar, 3 scatter/line, 1 scattermapbox, 1 heatmap** + tables
  (top microbes, top subtypes, tests drilldown, repeat offenders, official test
  table, data-quality summary, GSO audit).
- `PLOTLY_CONFIG = { displayModeBar:false, responsive:true }` → **no zoom/touch**
  on any chart except the map.
- `crossFilter(parentId, stateKey, value)` already wires click-to-filter on ~6
  charts (microbe, sector, GSO category, severity, map, one table). URL-hash view
  persistence + Views/bookmarks exist (2026-07 work). No tab structure yet.
- Reconciled totals: **20,881** rows (2024=9,317 · 2025=11,564), overall
  non-compliance **28.1%** (known-validity). Self-contained offline HTML (vendored
  Plotly + fonts). Masthead carries the Riyadh emblem.

## Visual direction (frontend-design)

**Principle:** this is the *instrument panel of a municipal food-safety lab*, and
it already has an identity (Riyadh emblem, heritage green/gold, the sunburst
deliverables). Extend that identity into the tabbed dashboard rather than invent a
new look — the whole R&D suite should feel like one lab record.

**Tokens (reuse + tighten what the dashboard already uses):**
- **Color** — ink `#1c2742` (existing navy); heritage `--green #006040`,
  `--gold #b3892b`; warm ground `--sand`/`--field`. A **disciplined 3-stop data
  palette** used consistently in *every* chart so the dashboard reads as one
  instrument: **compliant `#2f9e6b` → indicator `#e0a53a` → pathogen/NC `#c0392b`**,
  neutral slate `#64748b` for volume/context, year hues kept for YoY only.
- **Type** — display **Space Grotesk**; Arabic **Tajawal / IBM Plex Sans Arabic**
  (RTL-correct); **IBM Plex Mono** for all numbers/codes. Retire the Segoe-UI
  chart font for brand consistency.
- **Signature element — "lab-record divider" tabs.** The tab bar is not generic
  app tabs: it's styled like the index dividers on a physical specimen binder —
  a gold hairline baseline, the active tab lifting on a sand card with a ۞ najdi
  accent and a 2px green underline, each tab carrying its glyph + EN + Arabic
  label. This is the one memorable element; everything else stays quiet.
- **Restraint** — one consistent chart frame (transparent bg, hairline grid,
  mono ticks), generous spacing, at most two charts per row on desktop and one
  per row on touch. No chartjunk; the data palette does the talking.

## Architecture

The generated HTML gains a **tab shell** around the chart panels; the masthead,
filter bar, KPIs, and Views/bookmarks stay **pinned above the tabs** and apply
across all of them.

```
┌ masthead (emblem · title · build stamp) ────────────────┐
├ filter bar (year · time · location · product · microbe · Views/bookmarks) ┤
├ KPI strip (pinned) ─────────────────────────────────────┤
├ TAB BAR:  📊 Overview · 📍 Location · 🍱 Products · 🦠 Organisms · 📋 GSO & Quality ┤
├ ── active tab panel (only one visible) ── charts ───────┤
└ footer (self-contained · build stamp) ──────────────────┘
```

**Tab mechanics:**
- Each tab is a `<section class="tabpanel" data-tab="…">`; a `<nav class="tabs">`
  of buttons toggles `.active`. Inactive panels are `hidden` (not removed).
- **Plotly sizing across tabs:** Plotly can't lay out a chart in a
  `display:none` container. So: (a) render charts as normal on load, and (b) on
  tab activation call `Plotly.Plots.resize(node)` for each chart in the newly
  shown panel. Charts are created once; only resized on show.
- **Active tab in the URL hash:** extend the existing hash serializer with a
  `tab=` key so a shared link restores both the filter state and the open tab.
  `deserializeState()` selects the tab before the initial `applyFilters()`.

## Interactivity model (every chart)

- **Zoom / touch / pan:** a shared config
  `{ responsive:true, scrollZoom:true, displayModeBar:'hover',
     modeBarButtonsToRemove:['lasso2d','select2d','autoScale2d'], doubleClick:'reset' }`
  applied to all Plotly charts (map keeps its existing modebar). Pinch-zoom and
  drag-pan work on touch; double-tap resets.
- **Click-to-drill everywhere:** extend `crossFilter` to the charts that lack it —
  YoY (→ year/severity), sample-type (→ sample_type), chains (→ facility),
  heatmap cell (→ sector + organism), failed-tests (→ microbe). Tap any bar/cell
  and the whole dashboard (all tabs) re-filters. A tap on an already-active value
  toggles it off. Existing `crossFilter` chip-sync is reused.

## New: sortable GSO-info table (the "GSO in a tab" ask)

A plain HTML `<table>` in the GSO & Quality tab, built from the payload at build
time: one row per **GSO category** (or code) with columns **Category · code ·
samples · non-compliant · NC % · panel-complete % (2024) · top failing organism**.
Click a column header to sort (numeric-aware, asc/desc toggle, arrow indicator);
a header row stays sticky. Pure vanilla JS sort on the rendered rows — no library.
This *represents* the GSO numbers sortably; it makes no optional/required judgment.

## Edge cases / technical notes

- **Hidden-container Plotly:** always `Plotly.Plots.resize()` charts on tab-show;
  never create a chart while its panel is `hidden`.
- **Touch vs click:** `plotly_click` fires on tap; keep handlers idempotent so a
  double-tap (reset) doesn't double-filter.
- **Reduced motion / small screens:** tabs stack/scroll horizontally on narrow
  widths; charts go one-per-row < 760px.
- **Deep-link back-compat:** an old hash without `tab=` opens the Overview tab.
