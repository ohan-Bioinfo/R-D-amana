# Chemistry Dashboard — Standardize to the Micro Tabbed Touch-First Design

**Date:** 2026-08-11
**Status:** Approved for spec review (Muhannad)
**Scope:** chemistry only — `chemistry/reports/chemistry_dashboard.html`
(generated by `chemistry/scripts/build_dashboard.py`)

## Goal

Bring the chemistry dashboard to the **same design language** as the redesigned
microbiology dashboard: a 5-tab, touch-first instrument with lab-record-divider
tabs, zoom/pinch/touch on every chart, click-to-drill, active-tab-in-hash, and a
sortable GSO tab — so the two dashboards read as one R&D lab suite. Represent the
numbers; no new data judgments.

  metals/Honey/Jam/Hormones/Pesticides/Water) → year/compliance/sector chips → GSO
  category chips → KPI strips → ~9 panels + YoY.
- Panels: `chart-map`, `chart-monthly`, `chart-validity` (donut), `chart-municipalities`
  (sector), `chart-gso`, `chart-top-subtypes`, `chart-fail`, `tbl-facilities`,
  `tbl-categories`, `card-yoy` (hidden by default).
- Reconciled totals: **15,876 rows** across 8 sections (2024 + 2025), **1,133,621**
  distinct chemistry tests. Self-contained offline HTML; Riyadh masthead.
- **Already shares the micro design tokens** — `--green-900/700/500`, `--gold-700/500`,
  `--clay-500` (NC red), `--sand-50/100`, `--ink-900`; same masthead, KPI strip, and
  chip idioms. The *visual* half of standardization is essentially done.

## Architecture differences from micro (govern the port)

- Charts render via **`Plotly.newPlot(id, traces, layout, {responsive:true,
  displayModeBar:false})`** inline — there is no shared `reactChart`/`PLOTLY_CONFIG`.
  Standardizing zoom/touch means introducing a shared `PLOTLY_CONFIG` const and
  applying it at every `newPlot` call (~7 sites: monthly, validity, fail, gso, map,
  municipalities, top-subtypes).
- Filtering is **module state** (`currentSection`, `currentYear`, `activeSectors`
  Set, `activeGso` Set, `activeCompliance`) with chip `onclick` handlers that mutate
  the state and call **`renderAll()`**. There is **no URL-hash / `serializeState`
  machinery** — so "tab in hash" and "click-to-drill" are new (small) additions, not
  extensions of existing code.

## Visual direction

Reuse the identity that already exists (Riyadh emblem, heritage green/gold, warm
sand ground, clay-red NC). The one signature element is the **lab-record-divider
tab bar** — identical treatment to micro: gold hairline baseline, active tab lifted
on a sand card with a ۞ najdi accent + 2px green underline, each tab carrying its
glyph + EN + Arabic label. Everything else stays quiet.

## Architecture — tab shell

Masthead + Section bar + year/compliance/sector/GSO chips + KPI strips stay
**pinned above** the tabs and apply across all of them. The existing `<div class="grid">`
of cards is wrapped in five `<section class="tabpanel" data-tab="…">` blocks with a
`<nav class="tabnav">`; inactive panels are `hidden`; charts render once and
`Plotly.Plots.resize()` on tab-show (Plotly can't lay out in a hidden container).

```
┌ masthead (emblem · title · build stamp) ────────────────┐
├ Section bar · year/compliance/sector/GSO chips ─────────┤
├ KPI strips (pinned) ────────────────────────────────────┤
├ TABS: 📊 Overview · 📍 Location · 🧪 Products · ⚗️ Sections & tests · 📋 GSO & Quality ┤
├ ── active tab panel ── charts ──────────────────────────┤
└ footer ─────────────────────────────────────────────────┘
```

## Interactivity model (full parity)

- **Zoom / touch / pan:** a shared `PLOTLY_CONFIG =
  { responsive:true, scrollZoom:true, displayModeBar:'hover', displaylogo:false,
  doubleClick:'reset', modeBarButtonsToRemove:['lasso2d','select2d','autoScale2d',
  'toggleSpikelines'] }` applied to every `Plotly.newPlot`. Pinch-zoom / drag-pan on
  touch; double-tap resets.
- **Click-to-drill:** wire the two charts whose dimension maps to an existing filter —
  `chart-municipalities` tap → toggle that sector in `activeSectors` + `renderAll()`;
  `chart-gso` tap → toggle that category in `activeGso` + `renderAll()`. A tap on an
  already-active value toggles it off (matches chip behavior). Charts without a
  matching filter dimension (subtypes, monthly, validity, fail-tests) stay
  non-interactive — documented, not invented.
- **Active tab in the hash:** a minimal, tab-only hash (`#tab=<name>`). On tab click,
  `history.replaceState(null,'','#tab='+name)`; on load, read `location.hash` and
  `showTab` the saved tab (default Overview). Independent of the (absent) filter-hash.

## New: sortable GSO-info table (GSO & Quality tab)

A vanilla HTML `<table>` built from the payload: one row per **GSO category** with
columns **Category · Samples · Non-compliant · NC %** (chemistry has no per-category
GSO code column like micro's `gso_code`, so no Code column — verify against the
payload at build time; if a code field exists, include it). Header-click sort
(numeric-aware, asc/desc toggle, arrow indicator); sticky header. Represents the
numbers; makes no scope judgment.

## Edge cases / technical notes

- **Hidden-container Plotly:** always `Plotly.Plots.resize()` on tab-show; never
  create a chart while its panel is `hidden` (charts already render on load; the tab
  wrap keeps them in the DOM, just hidden).
- **Touch vs click:** keep `plotly_click` handlers idempotent so a double-tap (reset)
  doesn't double-toggle a filter.
- **`newPlot` vs `react`:** the shell keeps `newPlot` (charts are created fresh each
  `renderAll`); resize-on-show handles the hidden-container layout.
- **Reset filters** must continue to clear sector/GSO/compliance/search/year as today;
  the tab shell does not touch filter state.
- **Deep-link back-compat:** a hash without `tab=` opens Overview.
