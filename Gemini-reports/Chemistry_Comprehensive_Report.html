Enhancement Opportunities

🔴 Priority 1 — Data & Coverage Gaps BLOCKING

C1.1 2,519 Uncategorized 2024 Rows

2024 raw files lacked a Sample Category column. Currently uses regex fallback against sample_name. Many still fall to "Others" (أخرى) and get excluded from the pipeline output.

C1.2 167 Unspecified Invalid Pesticide Samples

Lab flagged is_valid = False but no single pesticide row exceeds limits. These appear as "Pesticide (unspecified)" in reports. Root cause unknown — may be lab-level overrides or multi-residue threshold logic.

C1.3 Jam Section — No Regulatory Limits

82/83 jam rows are no_limit. Marked DISPLAY_ONLY_SECTIONS. Need to confirm if GSO limits exist for jam or if this section should remain informational.

C1.4 Hormones & Antibiotics — 2024 Missing

Only 9 samples in 2025, zero in 2024. Cannot do YoY comparison. Confirm if 2024 data exists in the lab archives.

🟡 Priority 2 — Missing Analytical Features ANALYTICAL

C2.1 No Standalone Interactives (vs Micro's 7) High impact

Microbiology has Sankey, Treemap, Heatmap Matrix, Network Graph, Streamgraph. Chemistry only has 2 Sunbursts. Missing: Sankey (section → category → analyte → verdict), Heatmap Matrix (sector × failing analyte), Network (product ↔ analyte), Treemap (category → product → exceedance).

C2.2 Exceedance Magnitude Ranking Medium

The dashboard shows which tests fail but not how badly. Add an "Exceedance Magnitude" chart ranking the worst offenders by multiples-over-limit (e.g., the 298× Penconazole in parsley).

C2.3 Section-Level Trend Sparklines Low

Add inline sparklines to the section selector chips showing each section's monthly NC trend at a glance.

C2.4 Heavy Metals Surge Investigation Panel Medium

Given the +12 pp surge in heavy metals, a dedicated investigation panel showing: which analytes drove the increase, which product categories, which facilities, and timeline of onset.

C2.5 Analyte Co-Occurrence Matrix Medium

When a sample fails multiple analytes, which ones co-occur? Particularly relevant for heavy metals (Lead + Cadmium in the same fish sample).

C2.6 MoM Delta KPIs Medium

Add ▲/▼ trend arrows to the 10 KPI cards showing month-over-month change. Currently static snapshots.

🟢 Priority 3 — UX/UI Parity with Microbiology UX/UI

C3.1 Date Range Picker

Microbiology dashboard has date-from/date-to pickers. Chemistry only has year chips. Adding a date range would enable monthly/quarterly filtering.

C3.2 Bookmark Presets

Microbiology has 4 quick bookmark buttons ("2025 · pathogens only", etc.). Chemistry has none. Add: "Heavy Metals 2025", "Non-compliant only", "Pesticides surge", "Water quality".

C3.3 URL State Serialization

Microbiology serializes all filter state into the URL hash for shareable links. Chemistry does not. Add serializeState() / deserializeState().

C3.4 Severity Tier System

Microbiology has a 3-tier severity (indicator / pathogen / multi-pathogen). Chemistry has binary pass/fail. Add severity tiers based on exceedance magnitude: Minor (1–2× limit), Major (2–10× limit), Critical (>10× limit).

C3.5 Day-of-Week Cadence Chart

Microbiology has a DOW chart. Chemistry does not. Useful for identifying sampling volume gaps.

C3.6 Print Stylesheet & PDF Export

Add @media print and a "Download Report" button for field use.

🔵 Priority 4 — Strategic / Cross-Domain STRATEGIC

C4.1 Chemistry × Microbiology Cross-Correlation

Match facilities across both pipelines to answer: do facilities that fail chemistry also fail microbiology? Requires facility-name normalization across datasets.

C4.2 Limit-vs-Result Scatter Plot

For each analyte, plot (result value) vs (limit value) as a scatter — points above the y=x diagonal are exceedances. Instant visual triage of how close passing samples are to their limits.

C4.3 Predictive Risk Scoring

Compute a composite risk score per facility combining: number of failed sections, exceedance magnitude, recency, and repeat-offender status.
